02 · LESSON CONTENT

เนื้อหาบทเรียน

การใช้งาน Windows 11 ทั้ง 4 หัวข้อสำคัญ

CHAPTER 07
📱
7.1 · APPLICATIONS

1. การจัดการแอปพลิเคชันและไอคอน

การจัดการแอปพลิเคชันช่วยให้ผู้ใช้สามารถเรียกใช้งานโปรแกรมได้สะดวกและรวดเร็ว

1

Pin to Taskbar

การตรึงไอคอนบนทาสก์บาร์เพื่อความรวดเร็วในการเข้าถึง

2

Pin to Desktop

การนำไอคอนโปรแกรมมาไว้บนหน้าเดสก์ท็อป

3

Microsoft Store

แหล่งดาวน์โหลดแอปพลิเคชันที่ปลอดภัยและเป็นทางการ

4

Uninstall

การถอนการติดตั้งโปรแกรมที่ไม่ใช้งานออก

🖥️
7.2 · FEATURES

2. ฟีเจอร์และการจัดการหน้าจอ

Windows 11 มีฟีเจอร์ช่วยเพิ่มความสะดวกในการทำงานและปรับแต่งหน้าจอ

1

Snap Windows

ฟีเจอร์การแบ่งหน้าจอ จัดเรียงหลายโปรแกรมพร้อมกันได้อย่างเป็นระเบียบ

2

Microsoft Edge

โปรแกรมเว็บเบราว์เซอร์สำหรับการค้นหาข้อมูล

3

Display Settings

การตั้งค่าการแสดงผลและความละเอียดหน้าจอ

📁
7.3 · FILE EXPLORER

3. การใช้งาน File Explorer และ Context Menu

File Explorer เป็นเครื่องมือสำหรับจัดการไฟล์และโฟลเดอร์ภายในคอมพิวเตอร์

1

การจัดการไฟล์และโฟลเดอร์

สร้าง คัดลอก ย้าย และลบไฟล์ได้อย่างง่ายดาย

2

การเปิดหลายแท็บ (Tabs)

ใช้งานหลายโฟลเดอร์ในหน้าต่างเดียวโดยไม่ต้องเปิดซ้อนกัน

3

Context Menu

เมนูคลิกขวาและคำสั่งเพิ่มเติม (Show more options)

⚙️
7.4 · SYSTEM MANAGEMENT

4. การจัดการระบบเมื่อเครื่องค้างและการปิดเครื่อง

เรียนรู้การจัดการระบบเบื้องต้นเมื่อโปรแกรมไม่ตอบสนองและการปิดเครื่องอย่างถูกวิธี

1

Task Manager

เครื่องมือจัดการโปรแกรม กด Ctrl + Shift + Esc เพื่อเปิดอย่างรวดเร็ว

2

End Task

การบังคับปิดโปรแกรมที่ค้างหรือไม่ตอบสนอง

3

Power Options

การ Sleep, Shut down และ Restart ระบบ
