01 · Operating System Types

ประเภทของระบบปฏิบัติการ
มาตรฐานปิดและมาตรฐานเปิด

การเลือกใช้ระบบปฏิบัติการให้เหมาะสมกับงานและความต้องการของผู้ใช้

🪟

Windows (มาตรฐานปิด)

ระบบปฏิบัติการมีลิขสิทธิ์ มีรุ่นสำหรับผู้ใช้ทั่วไป (Home) ธุรกิจ (Pro) และองค์กร (Enterprise/Education)

🐧

Ubuntu (มาตรฐานเปิด)

ระบบปฏิบัติการบนพื้นฐาน Linux ใช้งานได้ฟรี ปรับแต่งได้ง่าย เหมาะสำหรับการเรียนรู้และพัฒนา

🖥️

FreeBSD

ระบบปฏิบัติการเสรีแบบ Unix-like โดดเด่นด้านเสถียรภาพ เหมาะสำหรับงานเซิร์ฟเวอร์และระบบเครือข่าย

📦

VMware Workstation

โปรแกรมจำลองเครื่องคอมพิวเตอร์ (Virtual Machine) สำหรับทดลองติดตั้งระบบปฏิบัติการต่างๆ

02 · Windows 11 Installation

ขั้นตอนการติดตั้ง
Windows 11

เตรียมความพร้อมและทำตามขั้นตอนการติดตั้ง Windows 11 ตั้งแต่การสร้าง USB Boot จนถึงการตั้งค่าหลังติดตั้ง

ขั้นตอนหลักในการติดตั้ง Windows 11

  • 1. การเตรียม USB Boot: ดาวน์โหลดไฟล์ ISO และใช้โปรแกรม Rufus เขียนลง USB Flash Drive (GPT/UEFI)
  • 2. การตั้งค่า BIOS: รีสตาร์ทเครื่อง เข้า BIOS (กด F2 หรือตามผู้ผลิต) แล้วตั้งค่าให้บูตจาก USB เป็นลำดับแรก
  • 3. การติดตั้งระบบ: บูตเข้าหน้าติดตั้ง เลือกภาษา คลิก Install Now ยอมรับเงื่อนไข และเลือกพาร์ทิชันที่ต้องการติดตั้ง
  • 4. การตั้งค่า OOBE: ตั้งค่าภูมิภาค เชื่อมต่ออินเทอร์เน็ต ลงชื่อเข้าใช้บัญชี Microsoft และตั้งรหัส PIN
03 · Ubuntu & VMware

การใช้งาน Ubuntu
ผ่านเครื่องเสมือน VMware

ทดลองใช้งานระบบปฏิบัติการ Linux บนเครื่องเสมือนโดยไม่ต้องติดตั้งลงเครื่องจริง

สร้าง Virtual Machine เปิด VMware เลือก Create New Virtual Machine เลือกไฟล์ ISO ของ Ubuntu และกำหนดขนาดฮาร์ดดิสก์เสมือน
การตั้งค่าภาษาไทย เข้าสู่เดสก์ท็อป Ubuntu ไปที่ Settings > Region & Language แล้วเลือกติดตั้งชุดภาษาไทยเพื่อใช้งานได้อย่างสะดวก
