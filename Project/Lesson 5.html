LESSON 05
🎮
5.1 · VGA CARD

การติดตั้งไดรเวอร์การ์ดจอ

การ์ดจอ (VGA Card) เป็นอุปกรณ์ที่ทำหน้าที่ประมวลผล และแสดงผลภาพบนหน้าจอคอมพิวเตอร์ การติดตั้งไดรเวอร์ที่ถูกต้องช่วยให้การแสดงผลทำงานได้อย่างเหมาะสม

1

ตรวจสอบรุ่นการ์ดจอ

กด Windows + R พิมพ์ dxdiag แล้วกด OK จากนั้นเลือกแท็บ Display และดูชื่อรุ่นในหัวข้อ Name

2

ดาวน์โหลดไดรเวอร์

ค้นหาไดรเวอร์จากเว็บไซต์อย่างเป็นทางการของผู้ผลิต โดยเลือกให้ตรงกับรุ่นอุปกรณ์

3

เริ่มติดตั้ง

แตกไฟล์และดับเบิลคลิก setup.exe จากนั้นเลือก AGREE AND CONTINUE

4

เลือกรูปแบบการติดตั้ง

เลือก Express สำหรับติดตั้งแบบแนะนำ หรือ Custom สำหรับกำหนดรายละเอียดเอง

5

เสร็จสิ้นการติดตั้ง

รอจนติดตั้งเสร็จเรียบร้อยแล้วคลิก Close

ข้อควรรู้: ควรตรวจสอบรุ่นการ์ดจอและระบบปฏิบัติการก่อนดาวน์โหลดไดรเวอร์ทุกครั้ง
🔊
5.2 · SOUND CARD

การติดตั้งไดรเวอร์การ์ดเสียง

การ์ดเสียง (Sound Card) ทำหน้าที่จัดการสัญญาณเสียง เพื่อให้คอมพิวเตอร์สามารถเล่นเสียงและใช้งานอุปกรณ์เสียงได้

1

ตรวจสอบรุ่นการ์ดเสียง

กด Windows + R พิมพ์ dxdiag กด OK และเลือกแท็บ Sound เพื่อดูชื่อรุ่นในหัวข้อ Name

2

ดาวน์โหลดไดรเวอร์

ค้นหาไดรเวอร์ที่ตรงกับรุ่น เช่น Realtek High Definition Audio Driver

3

ติดตั้งไดรเวอร์

ดับเบิลคลิกไฟล์ติดตั้งและดำเนินการตามคำแนะนำบนหน้าจอ

4

รีสตาร์ทคอมพิวเตอร์

เลือก Restart เพื่อเริ่มต้นระบบใหม่ตามที่โปรแกรมติดตั้งร้องขอ

🖨️
5.3 · PRINTER

การติดตั้งไดรเวอร์เครื่องพิมพ์

เครื่องพิมพ์ (Printer) เป็นอุปกรณ์ที่ใช้พิมพ์เอกสาร และต้องอาศัยไดรเวอร์ในการรับคำสั่งจากคอมพิวเตอร์

วิธีที่ 1 ติดตั้งผ่านเว็บไซต์ผู้ผลิต

1

เชื่อมต่อเครื่องพิมพ์

เชื่อมต่อสาย USB และเปิดเครื่องพิมพ์

2

ดาวน์โหลดไดรเวอร์

เข้าเว็บไซต์ผู้ผลิต เช่น Epson แล้วเลือกรุ่นและระบบปฏิบัติการให้ถูกต้อง

3

เริ่มติดตั้ง

ดับเบิลคลิกไฟล์ติดตั้ง เลือกภาษา และยอมรับข้อตกลง Agree

4

ตั้งค่าเครื่องพิมพ์

ตั้งค่าเป็นเครื่องพิมพ์เริ่มต้น (Default Printer) และดำเนินการตามขั้นตอน

5

ตรวจสอบการติดตั้ง

เมื่อปรากฏข้อความ Setup is complete แสดงว่าการติดตั้งเสร็จสิ้น

วิธีที่ 2 เพิ่มเครื่องพิมพ์ผ่าน Windows 10

1

เปิดการตั้งค่า

ไปที่ Settings → Devices → Printers & scanners

2

เพิ่มเครื่องพิมพ์

คลิก + Add a printer or scanner หากหาไม่พบให้เลือก The printer that I want isn't listed

3

กำหนดการเชื่อมต่อ

เลือก Add a local printer or network printer with manual settings และเลือกพอร์ตที่ใช้งาน เช่น USB001

4

เลือกไดรเวอร์

เลือกยี่ห้อและรุ่น หรือคลิก Have Disk... เพื่อเลือกไฟล์ไดรเวอร์นามสกุล .inf

5

ตั้งชื่อและแชร์เครื่องพิมพ์

ตั้งชื่อ เลือกการแชร์หรือไม่แชร์ แล้วคลิก Next จนเสร็จสิ้น

การทดสอบ: เปิด Microsoft Word ไปที่ File → Print เพื่อทดลองสั่งพิมพ์และตรวจสอบความพร้อมใช้งาน
🔄
5.4 · DRIVER UPDATE

การอัปเดตไดรเวอร์ (Updating Drivers)

การอัปเดตไดรเวอร์ช่วยปรับปรุงโปรแกรมควบคุมอุปกรณ์ แก้ไขข้อผิดพลาด และเพิ่มความเข้ากันได้กับระบบปฏิบัติการ

ช่องทางที่ 1 ผ่าน Device Manager

1

เปิด Device Manager

คลิกขวาที่ปุ่ม Start แล้วเลือก Device Manager

2

เลือกอุปกรณ์

คลิกขยายหมวดอุปกรณ์ที่ต้องการอัปเดต แล้วคลิกขวาที่อุปกรณ์นั้น

3

เลือก Update driver

คลิก Update driver เพื่อเข้าสู่หน้าต่างการอัปเดต

4

เลือกรูปแบบการค้นหา

Search automatically for updated driver software เพื่อค้นหาอัตโนมัติ หรือ Browse my computer for driver software เพื่อเลือกไฟล์ในเครื่อง

5

เสร็จสิ้น

รอจนระบบดำเนินการเสร็จ แล้วคลิก Close

ช่องทางที่ 2 ผ่าน Windows Update

1

ค้นหา Windows Update

พิมพ์ Check for updates ในช่อง Search

2

เปิด Advanced options

เข้าสู่ Advanced options เพื่อดูตัวเลือกเพิ่มเติม

3

เลือก Optional updates

เปิด Optional updates และตรวจสอบรายการ Driver updates

4

ดาวน์โหลดและติดตั้ง

เลือกรายการที่ต้องการแล้วคลิก Download & install

5

รีสตาร์ทระบบ

คลิก Restart now หากระบบร้องขอ

ประโยชน์ของการอัปเดต
  • แก้ไขข้อผิดพลาดในการทำงาน
  • เพิ่มประสิทธิภาพของอุปกรณ์
  • ปรับปรุงความเข้ากันได้กับระบบปฏิบัติการ
  • รองรับคุณสมบัติใหม่ ๆ
07 · FIRMWARE

การอัปเดตเฟิร์มแวร์
Firmware Update

เฟิร์มแวร์คือโปรแกรมขนาดเล็กที่ฝังอยู่ในชิปของอุปกรณ์ฮาร์ดแวร์ ทำหน้าที่ควบคุมการทำงานพื้นฐานของอุปกรณ์

💾
SYSTEM FIRMWARE

ขั้นตอนการอัปเดต System Firmware

สามารถตรวจสอบและจัดการรายการ System Firmware ผ่าน Device Manager ในระบบ Windows ได้

1

เปิด Device Manager

คลิกขวาที่ปุ่ม Start แล้วเลือก Device Manager

2

ค้นหาหมวด Firmware

คลิกขยายหัวข้อ Firmware เพื่อดูรายการอุปกรณ์

3

เลือก System Firmware

คลิกขวาที่ System Firmware แล้วเลือก Update Driver หรือเข้า Properties → Driver → Update Driver

4

ค้นหาไดรเวอร์

เลือก Search automatically for drivers เพื่อให้ระบบค้นหาไดรเวอร์ที่เหมาะสม

5

ตรวจสอบผลลัพธ์

หากปรากฏข้อความ The best drivers for your device are already installed ให้คลิก Close

ข้อควรระวัง: การอัปเดตเฟิร์มแวร์ประเภท BIOS หรือ UEFI ควรใช้ไฟล์ที่ตรงกับรุ่นอุปกรณ์จากผู้ผลิตเท่านั้น และไม่ควรปิดเครื่องระหว่างกระบวนการอัปเดต
