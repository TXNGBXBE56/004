01 · INTRODUCTION

ความหมายของโปรแกรมยูทิลิตี้ 🌟

ทำความรู้จักโปรแกรมอรรถประโยชน์และหน้าที่ในการช่วยดูแลระบบ

โปรแกรมยูทิลิตี้ (Utility Program) หรือโปรแกรมอรรถประโยชน์ คือซอฟต์แวร์ระบบที่ช่วยเพิ่มประสิทธิภาพ ของเครื่องคอมพิวเตอร์ ทำให้ผู้ใช้งานสามารถทำงานได้ง่ายและรวดเร็วขึ้น รวมถึงช่วยดูแลรักษาระบบและป้องกันการรบกวนจากโปรแกรมที่ไม่พึงประสงค์ โปรแกรมบางชนิดติดตั้งมาพร้อมกับระบบปฏิบัติการ ทำให้ผู้ใช้สามารถเรียกใช้งานได้ทันที

หน้าที่ของโปรแกรมยูทิลิตี้

⚡

เพิ่มประสิทธิภาพ

ช่วยให้คอมพิวเตอร์ทำงานได้สะดวกและมีประสิทธิภาพมากขึ้น

🛡️

ป้องกันภัยคุกคาม

ช่วยป้องกันไวรัสและโปรแกรมที่ไม่พึงประสงค์

🧹

ดูแลรักษาระบบ

ช่วยจัดการไฟล์และดูแลพื้นที่จัดเก็บข้อมูลของเครื่อง

📦

บีบอัดไฟล์

ลดขนาดไฟล์และช่วยให้สะดวกต่อการจัดเก็บหรือส่งข้อมูล

💾

สำรองข้อมูล

ช่วยเก็บสำเนาข้อมูลเพื่อป้องกันการสูญหาย

🗑️

ถอนการติดตั้ง

ช่วยยกเลิกการติดตั้งโปรแกรมที่ไม่ต้องการใช้งาน

ตัวอย่างโปรแกรมยูทิลิตี้

🧮

เครื่องคิดเลข (Calculator)

ใช้คำนวณตัวเลขและแปลงหน่วยต่าง ๆ

📝

โปรแกรมบันทึกข้อมูล

ใช้พิมพ์ข้อความและจดบันทึกข้อมูล

📸

โปรแกรมจับภาพหน้าจอ

ใช้บันทึกภาพหน้าจอเพื่อนำไปใช้งาน

🎙️

โปรแกรมบันทึกเสียง

ใช้บันทึกเสียงผ่านไมโครโฟนหรือชุดหูฟัง

02 · WINDOWS 10

การใช้งานบน Windows 10 🪟

โปรแกรมเครื่องมือพื้นฐานที่ช่วยอำนวยความสะดวกในการทำงาน

🪟 Windows 10 Utilities

โปรแกรมยูทิลิตี้บน Windows 10 ส่วนใหญ่สืบทอดมาจาก Windows 8 เช่น Calculator, Notepad, Paint และ Snipping Tool ซึ่งช่วยจัดการข้อความ รูปภาพ และการคำนวณได้อย่างสะดวกโดยไม่ต้องติดตั้งเพิ่มเติม

💱 ตัวอย่าง: ขั้นตอนการแปลงค่าเงิน (Currency) ใน Calculator
  1. คลิกปุ่ม Start หรือกดปุ่มโลโก้ Windows บนแป้นพิมพ์
  2. เลือกโปรแกรม Calculator โดยหน้าต่างเริ่มต้นจะแสดงแบบ Standard
  3. คลิกสัญลักษณ์ Open Navigation (☰)
  4. เลือกเครื่องมือ Currency
  5. เลือกสกุลเงินที่ต้องการเปรียบเทียบ เช่น Thailand - Baht และ United States - Dollar
  6. ป้อนตัวเลขที่ต้องการแปลงลงในช่อง
  7. คลิก Update rates เพื่ออัปเดตอัตราแลกเปลี่ยนล่าสุด
03 · WINDOWS 11

การใช้งานบน Windows 11 💻

ทำความรู้จักเครื่องมือพื้นฐานและคุณสมบัติที่เพิ่มเข้ามา

Windows 11 มีการปรับดีไซน์หน้าต่างโปรแกรมยูทิลิตี้ให้มีความโค้งมนและใช้งานง่ายยิ่งขึ้น สามารถเปิดใช้งานได้ผ่านเมนู All apps หรือพิมพ์ค้นหาในช่อง Search ได้อย่างรวดเร็ว
🧮

Calculator

เครื่องคิดเลขดีไซน์ใหม่ รองรับธีมมืดและโหมดการคำนวณที่หลากหลาย

📝

Notepad

รองรับระบบเปิดหลายแท็บ (Tabs) ในหน้าต่างเดียว สะดวกต่อการแก้ไขข้อความ

📸

Snipping Tool

เครื่องมือจับภาพและอัดวิดีโอหน้าจอในตัว สะดวกยิ่งขึ้น

04 · ANDROID

การใช้งานบน Android 📱

เครื่องมืออรรถประโยชน์บนระบบปฏิบัติการมือถือ

📁

Files by Google

จัดการไฟล์ ทำความสะอาดพื้นที่ว่าง และลบไฟล์ขยะในเครื่อง

⚙️

Device Care / Settings

ตรวจสอบสถานะแบตเตอรี่ พื้นที่จัดเก็บ และความปลอดภัยของระบบ
