03 · LESSON CONTENT

3.1 ส่วนประกอบหน้าจอ

รู้จักเครื่องมือสำคัญบนหน้าจอคอมพิวเตอร์ Windows 10

SECTION 6.1
🖥️
DESKTOP & TOOLS

องค์ประกอบหลักบนหน้าจอ

เมื่อเข้าสู่ระบบ Windows 10 หน้าจอหลักจะเรียกว่า Desktop ซึ่งเป็นพื้นที่ทำงานหลัก ประกอบด้วยไอคอนและเครื่องมืออำนวยความสะดวกต่าง ๆ ดังนี้:

1

Desktop

พื้นที่หน้าจอหลักสำหรับวางไอคอนโปรแกรม ไฟล์ และทางลัดต่าง ๆ

2

Start Menu

เมนูเริ่มต้นสำหรับเปิดโปรแกรม ค้นหาแอปพลิเคชัน และจัดการระบบ

3

Taskbar

แถบงานด้านล่างแสดงโปรแกรมที่กำลังเปิดใช้งานและปุ่มลัดโปรด

4

Search Bar

ช่องค้นหาไฟล์ โปรแกรม และข้อมูลภายในเครื่องได้อย่างรวดเร็ว

5

File Explorer

เครื่องมือจัดการไฟล์เอกสาร โฟลเดอร์ และไดรฟ์ในระบบ

6

Action Center

ศูนย์รวมการแจ้งเตือนและปุ่มทางลัดตั้งค่าด่วน (Wi-Fi, Bluetooth)

⚙️
SECTION 6.2

การใช้งานและการปรับแต่งเบื้องต้น

ผู้ใช้สามารถปรับเปลี่ยนรูปแบบหน้าจอตามความชอบส่วนตัว รวมถึงจัดระเบียบไฟล์ข้อมูลเพื่อให้ทำงานได้อย่างมีประสิทธิภาพ

1

การเปลี่ยนภาพพื้นหลัง

คลิกขวาบน Desktop เลือก Personalize จากนั้นเลือก Background เพื่อเปลี่ยนรูปภาพ

2

การปรับแต่งการตั้งค่า

เข้าสู่เมนู Settings (Windows + I) เพื่อปรับแต่งระบบ สีธีม และการแสดงผล

3

การจัดการไฟล์และโฟลเดอร์

เปิด File Explorer เพื่อสร้าง คัดลอก ย้าย และจัดเก็บเอกสารอย่างเป็นระเบียบ

04 · SHORTCUTS

แป้นพิมพ์ลัดที่ควรรู้

ช่วยให้ทำงานบน Windows 10 ได้รวดเร็วยิ่งขึ้น

KEYBOARD SHORTCUTS

ตารางแป้นพิมพ์ลัดลัดเลี่ยงการใช้เมาส์

แป้นพิมพ์ลัด หน้าที่การทำงาน
Ctrl + Cคัดลอกข้อมูลหรือไฟล์ที่เลือก
Ctrl + Vวางข้อมูลหรือไฟล์ที่คัดลอกไว้
Ctrl + Xตัดข้อมูลหรือย้ายไฟล์
Ctrl + Zย้อนกลับการทำงานล่าสุด (Undo)
Alt + Tabสลับหน้าต่างโปรแกรมที่กำลังเปิดใช้งาน
Windows + Dแสดงหน้า Desktop ทันที
Windows + Eเปิดโปรแกรม File Explorer
Windows + Iเปิดหน้าต่าง Settings การตั้งค่าระบบ
05 · SUMMARY

สรุปผลการเรียนรู้

ทบทวนสาระสำคัญของบทเรียน Windows 10

Windows 10 เป็นระบบปฏิบัติการที่มีความยืดหยุ่นสูง มีเครื่องมือและส่วนประกอบหน้าจอที่ใช้งานง่าย ไม่ว่าจะเป็น Desktop, Start Menu, File Explorer หรือการใช้แป้นพิมพ์ลัด ช่วยให้ผู้เรียนสามารถจัดการไฟล์ ปรับแต่งระบบ และใช้งานคอมพิวเตอร์ได้อย่างมีประสิทธิภาพและคล่องตัวในชีวิตประจำวัน 🤎
