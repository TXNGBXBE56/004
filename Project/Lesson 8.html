01 · INTRODUCTION

แนวคิดสำคัญ 🌱

ทำความรู้จักกับระบบปฏิบัติการ Ubuntu

Ubuntu (อูบุนตู) เป็นระบบปฏิบัติการประเภทเปิดเผยรหัสต้นฉบับ (Open Source) ที่พัฒนาขึ้นให้ใช้งานได้ฟรี ไม่มีค่าใช้จ่าย ผู้ใช้สามารถนำไปติดตั้งและใช้งานได้อย่างสะดวก มีซอฟต์แวร์และเครื่องมือต่าง ๆ ให้เลือกใช้งาน เหมาะสำหรับการศึกษา การทำงาน และการพัฒนาระบบคอมพิวเตอร์

🍡 Open Source คืออะไร?

แนวคิดการเปิดเผยรหัสต้นฉบับของซอฟต์แวร์ เพื่อให้ผู้ใช้งานสามารถศึกษา นำไปใช้ และพัฒนาต่อยอดได้ตามเงื่อนไขของสัญญาอนุญาตอย่างอิสระ

02 · SECTION 8.1

ส่วนประกอบของหน้าจอ Ubuntu

รู้จักตำแหน่งและหน้าที่ของส่วนต่าง ๆ บนหน้าจอ

🔍

1. Show Applications

ปุ่มแสดงแอปพลิเคชันทั้งหมดที่ติดตั้งในเครื่อง คล้ายปุ่ม Start ของ Windows

📌

2. Utility

แถบแอปพลิเคชันที่ปักหมุดไว้ เปิดใช้งานได้รวดเร็ว คล้าย Taskbar

🖥️

3. Virtual Desktop

หน้าจอเสมือนที่ช่วยแบ่งพื้นที่การทำงานออกเป็นหลายหน้าจอ

🕒

4. Date and Time

แสดงวันที่ เวลา ปฏิทิน และการแจ้งเตือนต่าง ๆ ในระบบ

♿

5. Accessibility

เครื่องมือช่วยการเข้าถึง เช่น Large Text และการเพิ่มความคมชัด

⚙️

6. Menu Bar

แถบเมนูตั้งค่าด่วน เช่น เสียง ความสว่าง อินเทอร์เน็ต และปิดเครื่อง

📁

7. Applications Icon

ไอคอนแอปพลิเคชันและโฟลเดอร์ต่าง ๆ บนหน้าจอ Desktop

🌄

8. Desktop Background

ภาพพื้นหลังของหน้าจอ พื้นที่หลักในการแสดงและใช้งานแอป

03 · SECTION 8.2

การใช้งาน Ubuntu เบื้องต้น

เรียนรู้การปรับแต่งหน้าจอและการตั้งค่าระบบ

1

การเปลี่ยนภาพพื้นหลัง

คลิกขวาบนพื้นที่ว่าง เลือก Change Background... เลือกภาพหรือกดเพิ่มรูปภาพส่วนตัว

2

การตั้งค่าหน้าจอ

เปิด Display Settings เพื่อปรับองศาและการแสดงผล (Orientation & Resolution)

3

การใช้ปุ่ม Super

Super Key (ปุ่ม Windows) ใช้เรียกหน้าภาพรวมและค้นหาแอปพลิเคชันอย่างรวดเร็ว

4

การตั้งค่าคีย์ลัด

เข้าไปที่ Settings > Keyboard > View and Customize Shortcuts เพื่อปรับแต่งปุ่มลัด

04 · KEYBOARD SHORTCUTS

คีย์ลัดที่ควรรู้ใน Ubuntu ⌨️

ช่วยให้ทำงานได้สะดวกและรวดเร็วยิ่งขึ้น

⌨️ Keyboard Shortcuts

เรียกเมนูแอปพลิเคชัน Alt + F1
เรียก Terminal Alt + F2
เปลี่ยนหน้าจอเสมือน Ctrl + Alt + ← / →
สร้างโฟลเดอร์ใหม่ Shift + Ctrl + N
แสดงไฟล์ที่ซ่อน Ctrl + H
ยกเลิกคำสั่ง Terminal Ctrl + C
เคลียร์หน้าจอ Terminal Ctrl + L
05 · SECTION 8.3

แอปพลิเคชันพื้นฐานของ Ubuntu

ตัวอย่างโปรแกรมที่ใช้ในการทำงานประเภทต่าง ๆ

⌨️

1. Terminal

รับคำสั่งแบบ Command Line ทำงานรวดเร็ว ใช้ทรัพยากรน้อย

Command Prompt (cmd.exe)
📊

2. LibreOffice Calc

โปรแกรมตารางคำนวณ สร้างตารางและกราฟข้อมูล

Microsoft Excel
🎨

3. LibreOffice Draw

ใช้วาดภาพ สเกตช์ แปลน ผังไดอะแกรม และภาพเวกเตอร์

Microsoft Visio
📽️

4. LibreOffice Impress

โปรแกรมสร้างงานนำเสนอและสไลด์มัลติมีเดีย

Microsoft PowerPoint
📝

5. LibreOffice Writer

ใช้พิมพ์เอกสาร รายงาน จดหมาย และส่งออก PDF

Microsoft Word
📸

6. Take a Screenshot

จับภาพหน้าจอ เลือกพื้นที่ที่ต้องการและบันทึกอัตโนมัติ

Snipping Tool
🖼️

7. Shotwell

จัดการและตกแต่งรูปภาพ ครอป หมุน และปรับแสง

Microsoft Photos
🧮

8. Calculator

เครื่องคิดเลข 5 โหมด (พื้นฐาน, ขั้นสูง, การเงิน, โปรแกรมมิ่ง)

Windows Calculator
🎵

9. Rhythmbox

เครื่องเล่นเพลง ฟังพอดแคสต์และวิทยุออนไลน์

Windows Media Player
✉️

10. Mozilla Thunderbird

โปรแกรมรับส่งอีเมล รองรับบัญชีหลากหลาย

Microsoft Outlook
