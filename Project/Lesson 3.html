01 · Cloud Computing

ความหมายและประโยชน์
ของ Cloud Computing

การประมวลผลบนกลุ่มเมฆ คือการใช้ทรัพยากรคอมพิวเตอร์ผ่านเครือข่ายอินเทอร์เน็ต โดยไม่จำเป็นต้องติดตั้งหรือดูแลระบบทั้งหมดด้วยตนเอง

การประมวลผลบนกลุ่มเมฆ (Cloud Computing) คือ การให้บริการทรัพยากรคอมพิวเตอร์ผ่านเครือข่ายอินเทอร์เน็ต เช่น พื้นที่จัดเก็บข้อมูล เซิร์ฟเวอร์ โปรแกรม และระบบประมวลผล ผู้ใช้สามารถเข้าถึงบริการได้จากอุปกรณ์ที่เชื่อมต่ออินเทอร์เน็ต

💰

ลดค่าใช้จ่าย

ลดความจำเป็นในการซื้ออุปกรณ์คอมพิวเตอร์และซอฟต์แวร์ราคาแพง รวมถึงลดค่าใช้จ่ายในการดูแลระบบ

🌐

เข้าถึงได้ทุกที่

ใช้ข้อมูลหรือบริการผ่านอินเทอร์เน็ตได้จากหลายอุปกรณ์และหลายสถานที่

📈

ปรับขนาดได้ยืดหยุ่น

เพิ่มหรือลดทรัพยากรที่ต้องใช้ได้ตามความต้องการของผู้ใช้งาน

🛠️

ดูแลระบบง่ายขึ้น

ผู้ให้บริการรับผิดชอบดูแลโครงสร้างพื้นฐานและระบบส่วนหนึ่งแทนผู้ใช้

💡 ตัวอย่าง: ใช้ Google Drive เก็บไฟล์ออนไลน์ หรือใช้ Google Docs ทำงานร่วมกันผ่านเว็บเบราว์เซอร์
02 · System Structure

โครงสร้างการทำงาน
ของ Cloud Computing

ระบบ Cloud Computing เชื่อมต่ออุปกรณ์ของผู้ใช้เข้ากับระบบของผู้ให้บริการ ผ่านเครือข่ายอินเทอร์เน็ต โดยมีองค์ประกอบหลักสองส่วน

💻

Front End

ส่วนที่ผู้ใช้มองเห็นและใช้งาน เช่น คอมพิวเตอร์ โทรศัพท์ เว็บเบราว์เซอร์ และหน้าจอแอปพลิเคชัน

⇄
🖥️

Back End

ส่วนที่ทำงานอยู่เบื้องหลัง เช่น เซิร์ฟเวอร์ พื้นที่จัดเก็บข้อมูล ระบบประมวลผล และระบบเครือข่าย

⚙️

ระบบจัดการทรัพยากร

ควบคุมและจัดสรรทรัพยากร เช่น หน่วยประมวลผล หน่วยความจำ และพื้นที่จัดเก็บข้อมูล ให้เหมาะสมกับการใช้งาน

🔐

ระบบรักษาความปลอดภัย

ช่วยควบคุมการเข้าถึง ตรวจสอบการใช้งาน และสนับสนุนการสำรองข้อมูลเพื่อป้องกันข้อมูลสูญหาย

03 · Deployment Models

รูปแบบการให้บริการ
Cloud Computing

รูปแบบการให้บริการแบ่งตามลักษณะการใช้งานและการจัดการระบบได้ 4 รูปแบบ

Public Cloud

บริการคลาวด์ที่เปิดให้ผู้ใช้ทั่วไปหรือองค์กรเช่าใช้งานผ่านผู้ให้บริการ โดยใช้โครงสร้างพื้นฐานร่วมกัน

คลาวด์สาธารณะ

Private Cloud

คลาวด์ที่จัดไว้สำหรับองค์กรเดียว ช่วยให้องค์กรควบคุมการใช้งานและการจัดการระบบได้มากขึ้น

คลาวด์ส่วนตัว

Community Cloud

คลาวด์ที่หลายองค์กรซึ่งมีความต้องการหรือข้อกำหนดใกล้เคียงกันใช้ร่วมกัน

คลาวด์ชุมชน

Hybrid Cloud

การผสมผสานคลาวด์ตั้งแต่สองรูปแบบขึ้นไป เช่น Public Cloud ร่วมกับ Private Cloud

คลาวด์แบบผสม
04 · Cloud Service Types

ประเภทบริการของ
Cloud Computing

บริการหลัก 3 รูปแบบ ได้แก่ SaaS, PaaS และ IaaS

ประเภทบริการ ลักษณะการให้บริการ ตัวอย่าง
SaaS
Software as a Service		 ให้ผู้ใช้ใช้งานโปรแกรมผ่านอินเทอร์เน็ต โดยไม่ต้องติดตั้งหรือดูแลระบบเบื้องหลังเอง Google Docs, Microsoft 365, Gmail, Google Drive, OneDrive, Dropbox
PaaS
Platform as a Service		 ให้แพลตฟอร์มและเครื่องมือสำหรับพัฒนา ทดสอบ และติดตั้งแอปพลิเคชัน Google App Engine, Microsoft Azure App Service, AWS Elastic Beanstalk
IaaS
Infrastructure as a Service		 ให้เช่าทรัพยากรโครงสร้างพื้นฐาน เช่น เครื่องเสมือน เครือข่าย พื้นที่จัดเก็บ และระบบประมวลผล Amazon Web Services (AWS), Microsoft Azure, Google Compute Engine
📝 จำง่าย ๆ: SaaS คือใช้โปรแกรม, PaaS คือใช้แพลตฟอร์มพัฒนาโปรแกรม และ IaaS คือเช่าทรัพยากรโครงสร้างพื้นฐาน
05 · Google Drive

การใช้งาน
Google Drive

ตัวอย่างบริการจัดเก็บและแบ่งปันไฟล์บนคลาวด์ ช่วยให้ผู้ใช้จัดการไฟล์ออนไลน์ และทำงานร่วมกับผู้อื่นได้

Google Drive เป็นบริการจัดเก็บไฟล์ออนไลน์ ผู้ใช้สามารถอัปโหลด ดาวน์โหลด จัดระเบียบ และแบ่งปันไฟล์กับผู้อื่นได้ โดยบัญชี Google ทั่วไปมีพื้นที่จัดเก็บฟรี 15 GB ซึ่งใช้ร่วมกับบริการของ Google บางรายการ

ขั้นตอนการใช้งานเบื้องต้น

1

เข้าสู่ระบบ

เปิด Google Drive ผ่านเว็บเบราว์เซอร์ แล้วเข้าสู่ระบบด้วยบัญชี Google

2

อัปโหลดไฟล์

เลือก “ใหม่” หรือ “New” แล้วเลือกอัปโหลดไฟล์หรือโฟลเดอร์จากอุปกรณ์

3

แบ่งปันไฟล์

เลือกไฟล์ กด “แชร์” แล้วกำหนดผู้ที่เข้าถึงไฟล์และสิทธิ์การใช้งาน

การตั้งค่าการแบ่งปัน

ตัวเลือก ความหมาย
Restricted
จำกัด		 เฉพาะผู้ที่ได้รับอนุญาตเท่านั้นจึงจะเปิดไฟล์ได้
Anyone with the link
ทุกคนที่มีลิงก์		 ผู้ที่มีลิงก์สามารถเข้าถึงไฟล์ได้ตามสิทธิ์ที่กำหนด ควรตรวจสอบการตั้งค่าก่อนส่งลิงก์

สิทธิ์ในการเข้าถึงไฟล์

👁️

Viewer — ผู้ดู

สามารถเปิดดูไฟล์ได้ แต่ไม่สามารถแก้ไขเนื้อหาได้

💬

Commenter — ผู้แสดงความคิดเห็น

สามารถดูไฟล์และแสดงความคิดเห็นได้ แต่ไม่สามารถแก้ไขเนื้อหาหลัก

✏️

Editor — ผู้แก้ไข

สามารถแก้ไขเนื้อหาและทำงานร่วมกับผู้ใช้อื่นได้ตามสิทธิ์ที่ได้รับ

🔒

ข้อควรระวัง

ไม่ควรตั้งค่าแชร์เป็น “ทุกคนที่มีลิงก์” สำหรับไฟล์ที่มีข้อมูลส่วนตัวหรือข้อมูลสำคัญ
